# PRIDE submission

*Contributed by April*

1. Prepare the following documents:
- Your organized raw files
- Your data analysis files
- Abstract (does not need to be the final version)
- Methods (does not need to be the final version)
- Keywords
- FASTA
1. Go to R2D2 and find px-submission-tool in the download folder on the F drive.
2. Open px-submission-tool-versionnumber.jar.
3. Create an account.
4. Log in.
5. Select partial submission.
6. Input dataset details and hit next to fill in the information (You will need to know the instrument name and the digestion enzyme used during the experiment). Put Dr. Fried's information under "Lab Head".
